Инструмент для создания и управления виртуальными машинами

2026 • DevOps практика

Что такое Vagrant

Vagrant — это инструмент, который позволяет быстро создавать и настраивать виртуальные машины через конфигурационный файл.

Он часто используется вместе с VirtualBox, Docker или другими провайдерами.

Зачем он нужен

  • Быстрое создание тестовых окружений
  • Повторяемость инфраструктуры
  • Удобство для разработки
  • Работа в команде с одинаковыми окружениями

Плюсы и минусы Vagrant

Плюсы

  • У виртуальных машин Vagrant одинаковая среда. У всех разработчиков будет запускаться одинаковые виртуальные машины.
  • Вся настройка будущей виртуальной машины происходит в одном файле.
  • Запуск и остановка всегда происходит одной командой (vagrant up и vagrant halt).
  • Программы и базы данных можно легко установить при первом запуске
  • Vagrant работает с VirtualBox , VMware и т.д.

Минусы

  • Каждый новый образ весит гигабайты. Это большой размер виртуальных машин.
  • Большая наргрузка на процессор и потребление оперативной памяти.

Пример Vagrantfile

Пример

Vagrant.configure("2") do |config|

  config.vm.box = "ubuntu/bionic64"

  config.vm.network "private_network",
    ip: "192.168.33.10"

  config.vm.provider "virtualbox" do |vb|
    vb.memory = "1024"
  end

end

Из моего проекта:


        # -*- mode: ruby -*-
# vi: set ft=ruby :

# All Vagrant configuration is done below. The "2" in Vagrant.configure
# configures the configuration version (we support older styles for
# backwards compatibility). Please don't change it unless you know what
# you're doing.
# -*- mode: ruby -*-
# vi: set ft=ruby :

Vagrant.configure("2") do |config|
  config.vm.box_check_update = false

  # ============ Контроллер Ansible на AlmaLinux 8 =============
  config.vm.define "ansible-controller" do |controller|
    controller.vm.box = "generic/alma8"
    controller.vm.hostname = "controller"

    controller.vm.network "private_network", ip: "192.168.56.10"

    controller.vm.provision "shell", inline: <<-SHELL
      sudo dnf -y update
      sudo dnf -y install epel-release
      sudo dnf -y install ansible
    SHELL
  end

  # ============ Ubuntu Server =============
  config.vm.define "ubuntu-server1" do |server1|
    server1.vm.box = "ubuntu/focal64"
    server1.vm.hostname = "ubuntu-server1"

    server1.vm.network "public_network"
    server1.vm.network "private_network", ip: "192.168.56.11"

    server1.vm.provision "shell", inline: <<-SHELL
      sudo apt-get update -y
    SHELL
  end
end
