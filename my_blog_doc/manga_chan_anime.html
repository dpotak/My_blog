Manga-Anime-Chan

Это проект в котором прекрасно сочетаются чтение манги и просмотр аниме.

Он позволяет пользователям удобно просматривать контент, обсуждать любимые произведения и следить за новостями индустрии.

Идея проекта

Этот проект — платформа, где можно смотреть аниме и читать мангу в одном месте.

Цель — объединить контент и сделать удобный интерфейс для пользователя.

Технологии

  • Frontend: React
  • Backend: Flask (Python)
  • Database: MongoDB
  • Keys: SSH
  • Automation: Ansible
  • Server: Apache2 / Centos 7 и Ubuntu Linux

Архитектура

   Client (React)
        ↓
   API (Flask)
        ↓
   Database (MongoDB)
        ↓
 Deployment (Ansible / Centos 7 -> Ubuntu Linux)

Статус разработки

Проект находится в активной разработке. Настраивается инфраструктура и базовая логика.
