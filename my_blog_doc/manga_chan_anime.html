Manga-Chan / Anime-Chan

О проекте, архитектуре и идее

2026 • проект разработки

Идея проекта

Этот проект — платформа, где можно смотреть аниме и читать мангу в одном месте.

Цель — объединить контент и сделать удобный интерфейс для пользователя.

Технологии

  • Frontend: React
  • Backend: Flask (Python)
  • Database: MongoDB
  • Automation: Ansible
  • Server: Apache2 / Linux

Архитектура

Client (React)
        ↓
   API (Flask)
        ↓
   Database (MongoDB)
        ↓
 Deployment (Ansible / Linux)

Статус разработки

Проект находится в активной разработке. Настраивается инфраструктура и базовая логика.
