Что такое Ansible

15 июня 2026 • 5 мин чтения

Ansible — это инструмент автоматизации, который позволяет управлять серверами.

С его помощью можно автоматически устанавливать программы, обновлять конфигурации и запускать команды сразу на нескольких машинах.

Пример структуры проекта

ansible/

├── inventory

├── playbooks

└── roles

Для своего проекта я использую Ansible для подготовки сервера под Flask, React и MongoDB.

Пример playbook 

- hosts: all
  become: true

  tasks:

    - name: install nginx
      apt:
        name: nginx
        state: present

Дальше можно продолжать статью сколько угодно — страница будет листаться автоматически.
